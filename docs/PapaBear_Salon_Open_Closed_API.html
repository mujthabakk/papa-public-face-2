Salon Open / Closed Label — Timing API

How the public app shows Open / Closed on shop page & Nearby. Backend must send correct timing so labels work.

1. What the app shows

On salon / shop detail page (and Nearby list cards):

  • Badge (top of hero): green Open or grey Closed
  • Hours line: Open until 9:00 PM or Closed · Opens at 10:00 AM

Important: The public app does not require a separate Open/Closed API flag on the shop page. It calculates status from the salon timing array + the device local clock.

2. APIs that must return timing

Send a timing field on these responses:

  • api/v1/salon/salonDetails — shop page
  • api/v1/salon/getHomeData — home salon list
  • Nearby / search salon objects

3. Required timing format

Accept either a JSON array or a JSON string. Preferred: array.

"timing": [
  { "day": 0, "open_time": "10:00", "close_time": "21:00" },
  { "day": 1, "open_time": "10:00", "close_time": "21:00" },
  { "day": 2, "open_time": "10:00", "close_time": "21:00" },
  { "day": 3, "open_time": "10:00", "close_time": "21:00" },
  { "day": 4, "open_time": "10:00", "close_time": "21:00" },
  { "day": 5, "open_time": "10:00", "close_time": "21:00" },
  { "day": 6, "open_time": "10:00", "close_time": "21:00" }
]
Field Type Rule
day int 0 = Sunday, 1 = Monday … 6 = Saturday
open_time string 24-hour HH:mm e.g. "10:00" (not "10:00 AM")
close_time string 24-hour HH:mm e.g. "21:00"

Overnight hours (e.g. 20:00 → 02:00): close_time may be earlier than open_time. App adds 24 hours.

Closed all day: omit that day’s row, or do not send times for that day.

4. Optional helper fields (Nearby fallback)

If timing is empty, Nearby may fall back to:

"is_open": true,
"open_now": 1

true / "1" = open. Shop detail page still prefers timing.

5. How the public app decides Open vs Closed

  1. Pick today’s day with Dart: DateTime.now().weekday % 7
    Monday=1 … Sunday=7 → Sunday becomes 0.
  2. Find the timing row where day matches today.
  3. If no row for today → Closed.
  4. If now is between open_time and close_time → Open.
  5. Else → Closed · Opens at {today open_time in 12-hour}.

Example: today Saturday (day: 6), open 10:00, phone 7:07 AM → Closed · Opens at 10:00 AM. After 10:00 AM → Open / Open until ….

Uses device local time, not salon timezone.

6. Checklist for backend team

  1. Always send a full 7-day timing array (or only open days).
  2. Use day map 0–6 (Sunday=0). Do not use 1–7 Monday-first unless the app is changed.
  3. Times must be HH:mm (24-hour), not 10:00 AM.
  4. Optional: also send is_open / open_now in sync with those hours for list screens.
  5. If salon is closed today: omit that day — do not send 00:00–00:00 unless it means open midnight–midnight.
  6. Keep partner/admin UI day map identical so saved hours match what the public app expects.
